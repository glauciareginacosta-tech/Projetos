# Projeto de Coleta de Dicas de Investimento para Usuários de um Site

Este projeto em Python foi desenvolvido para coletar informações de usuários de um site e fornecer dicas de investimento personalizadas. O sistema realiza um loop para buscar uma dica de investimento para cada usuário e, ao final, grava todas as informações coletadas em um arquivo para análise posterior.

## Funcionalidades

- Leitura de informações de usuários de um website
- Para cada usuário, busca uma dica de investimento personalizada
- Salva todas as informações em um arquivo de saída (CSV)

## Pré-requisitos

- Python 3.x
- Bibliotecas necessárias: `requests`, `pandas`, `os`, `OpenRouter` etc.

## Como usar

1. Baixe o arquivo: ProjetoDicasInvestimentos.ipynb

Investment Tip Collection Project for Website Users

This Python project has been developed to gather user information from a website and provide personalized investment tips. The system operates in a loop to retrieve an investment tip for each user and, upon completion, records all collected data into a file for subsequent analysis.

## Features

- Reading user information from a website
- For each user, retrieving a personalized investment tip
- Saving all data to an output file (CSV)

## Prerequisites

- Python 3.x
- Required libraries: `requests`, `pandas`, `os`, `OpenRouter`, etc.

## Instructions for Use

1. Download the file: `ProjetoDicasInvestimentos.ipynb`
2. Open it in Google Colab
3. Add an AI API key generated from the OpenRouter website and execute the notebook.
