# Project Documentation - HELLOWORLD - CrewAI

## System Overview

This project is a Python application that utilizes CrewAI to generate creative ideas for posts about the benefits of studying Machine Learning. It combines the natural language processing capabilities of the OpenRouter API with a framework of agents and tasks, allowing for the rapid and efficient creation of ideas. The result is stored in a Markdown file, facilitating access and editing of the generated ideas.

## Technologies

### Python <img src="https://www.python.org/static/community_logos/python-logo.png" alt="Python" width="100" />
Python is a high-level programming language.

### CrewAI <img src="https://github.com/crewAIInc.png" alt="CrewAI" width="25" />
CrewAI is a library that simplifies working with artificial intelligence and natural language processing, enabling the development of interactive applications with agents and tasks to meet various needs. In this project, we are leveraging CrewAI to orchestrate the generation of creative ideas using a specific AI-based model.

## How to Run

### Prerequisites

Open the attached "HELLOWORLD-CrewAI.ipynb" file in Colab.

### Setup

Before running the code, you must:
1 - Register the OpenRouter API key in the *Secrets* section of Colab with the name: OPENROUTER_API_KEY

### Running the Code

Execute the code in Colab. The result will be generated and saved in a Markdown file in the format `ideas_<current_date>.md`.

### Notes

- Make sure you have an active internet connection, as the application makes calls to the OpenRouter API.
- The generated file will contain the creative ideas formatted in Markdown, ready to be used.

# Documentação do Projeto - HELLOWORLD - CrewAI

## Resumo do Sistema

Este projeto é uma aplicação em Python que utiliza o CrewAI para gerar ideias criativas de posts sobre os benefícios do estudo em Machine Learning. Ele combina a capacidade de processamento de linguagem natural da API OpenRouter com uma estrutura de agentes e tarefas, permitindo a criação de ideias de forma rápida e eficiente. O resultado é armazenado em um arquivo Markdown, facilitando o acesso e a edição das ideias geradas.

## Tecnologias

### Python <img src="https://www.python.org/static/community_logos/python-logo.png" alt="Python" width="100" />
Python é uma linguagem de programação de alto nível.

### CrewAI <img src="https://github.com/crewAIInc.png" alt="CrewAI" width="25" />
CrewAI é uma biblioteca que facilita o trabalho com inteligência artificial e processamento de linguagem natural, permitindo desenvolver aplicativos interativos com agentes e tarefas para atender a diversas necessidades. Neste projeto, estamos aproveitando o CrewAI para orquestrar a geração de ideias criativas usando um modelo específico baseado em IA.

## Como Rodar

### Pré-requisitos

Abra o arquivo anexo "HELLOWORLD-CrewAI.ipynb" no colab.

### Configuração

Antes de executar o código, você deve:
1 -  cadastrar a chave da API da OpenRouter no *Secrets* do Colab com o nome: OPENROUTER_API_KEY

### Executando o Código

Execute o código no colab. O resultado será gerado e salvo em um arquivo Markdown no formato `ideias_<data_atual>.md`.

### Observações

- Assegure-se de ter uma conexão com a internet ativa, pois a aplicação faz chamadas para a API da OpenRouter.
- O arquivo gerado conterá as ideias criativas formatadas em Markdown, prontas para serem utilizadas.
