# Demand Analysis Dashboard in Function Point

## Overview
This project consists of an interactive dashboard developed in Excel, aimed at analyzing and comparing the functional sizes of requirements captured in Function Points. The database was initially processed and calculated using Python, providing a detailed analysis of the differences between evaluations performed by experts and artificial intelligence.

## Features
- **Data Importation:** Data for six requirements, calculated by both experts and AI, are imported and displayed within the dashboard.
- **Functional Size Comparison:** Visualization of absolute and percentage differences between the functional sizes evaluated by the two methods.
- **Difference Analysis:** Charts and tables that facilitate understanding of variations and discrepancies between assessments.
- **AI Justification:** A playful feature where a question regarding the differences between methods was posed to AI. The generated response was incorporated into the dashboard as a demonstration of skills in querying AI via Python.

## Technologies Used
- **Python:** For initial data processing, calculation of differences and percentages, and interaction with AI.
- **Excel:** For creating the dashboard, visualizations, and presenting the final results.

## Development Process
### Data Calculation:
- Collection of evaluations from experts.
- Simulation or generation of evaluations by AI.
- Calculation of differences and percentages using Python.
- Export of results to an Excel file.

### Dashboard Creation:
- Import of data into Excel.
- Development of pivot tables, charts, and visual elements to facilitate analysis.

### AI Interaction:
- As a demonstration, a question about the reasons behind the differences between the functional sizes was posed to AI.
- The response obtained was added to the dashboard as a playful element, showcasing the use of AI queries via Python.

## Notes
- The question posed to AI and the generated response were created solely for demonstration purposes and do not constitute a technical analysis.
- This project aims to showcase skills in data analysis, automation with Python, and integration of artificial intelligence into analytical processes.

## How to Use
1. Open the Excel dashboard file.
2. Update data as needed or import new results calculated via Python.
3. Use the charts and tables to explore the differences between evaluations.
4. Refer to the AI justification section for an entertaining explanation of possible reasons for discrepancies.

## Contributions
This project was developed for academic purposes and to demonstrate technical skills. Feedback and suggestions for improvements are welcome!

# Dashboard de Análise de Demandas em Ponto de Função

## Visão Geral

Este projeto consiste em um dashboard interativo desenvolvido em Excel, cujo objetivo é analisar e comparar os tamanhos funcionais de demandas captadas em ponto de função. A base de dados foi inicialmente processada e calculada em Python, trazendo uma análise detalhada sobre as diferenças entre as avaliações feitas por especialistas e por inteligência artificial.

## Funcionalidades

- **Importação de Dados:** Os dados das seis demandas em ponto de função, calculados por especialistas e por IA, são importados e apresentados no dashboard.
- **Comparativo de Tamanhos Funcionais:** Visualização das diferenças absolutas e percentuais entre os tamanhos funcionais avaliados pelos dois métodos.
- **Análise de Diferenças:** Gráficos e tabelas que facilitam a compreensão das variações e discrepâncias entre as avaliações.
- **Justificativa da IA:** Uma brincadeira criada com IA, onde uma pergunta sobre a diferença entre os métodos foi feita à inteligência artificial. A resposta gerada foi adicionada ao dashboard para fins de demonstração de habilidades em consultas à IA via Python.

## Tecnologias Utilizadas

- **Python:** Para o processamento inicial dos dados, cálculos das diferenças e percentuais, além da interação com IA.
- **Excel:** Para a criação do dashboard, visualizações, e apresentação dos resultados finais.

## Processo de Desenvolvimento

1. **Cálculo dos Dados:** 
   - Coleta das avaliações de especialistas.
   - Simulação ou geração de avaliações pela inteligência artificial.
   - Cálculo das diferenças e percentuais em Python.

2. **Exportação dos Dados:** Os resultados calculados foram exportados para um arquivo Excel.

3. **Criação do Dashboard:** 
   - Importação dos dados no Excel.
   - Desenvolvimento de tabelas dinâmicas, gráficos e elementos visuais para facilitar a análise.

4. **Interação com IA:** 
   - Como uma demonstração de conhecimento, foi questionado à IA o motivo das diferenças entre os tamanhos funcionais.
   - A resposta obtida foi adicionada ao dashboard como uma brincadeira, evidenciando o uso de consultas à IA via Python.

## Observações

- A questão à IA e a resposta gerada foram criadas exclusivamente para fins de demonstração e não representam uma análise técnica real.
- O projeto busca evidenciar habilidades em análise de dados, automação com Python e integração de inteligência artificial em processos de análise.

## Como Utilizar

1. Abra o arquivo Excel do dashboard.
2. Atualize os dados conforme necessário ou importe novos resultados calculados pelo Python.
3. Utilize os gráficos e tabelas para explorar as diferenças entre as avaliações.
4. Consulte a seção de justificativa da IA para uma leitura divertida sobre as possíveis razões das diferenças.

## Contribuições

Este projeto foi desenvolvido para fins acadêmicos e de demonstração de habilidades técnicas. Feedbacks e melhorias são bem-vindos!


**Nota:** Este projeto é uma combinação de análise técnica e uma brincadeira com inteligência artificial, demonstrando a integração de diferentes tecnologias para fins educativos e de apresentação de conhecimentos.
